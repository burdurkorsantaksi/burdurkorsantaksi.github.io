# Burdur Korsan Taksi

Burdur korsan taksi yolcusu uçak için komşu ile geçer ama yol uzun değildir. Isparta Süleyman Demirel Havalimanı Burdur merkezden 32 kilometre, 29 dakika uzaklıktadır. Güneydeki ilçelerde durum değişir; Altınyayla'dan çıkan için Antalya Havalimanı 155 kilometreyle daha yakındır.

Beyaz kumsalıyla bilinen Salda Gölü yazın en çok gidilen yerdir; Yeşilova havalimanına 94 kilometredir. Ağlasun'daki Sagalassos antik kenti yüksekte kurulduğundan araç ören yeri otoparkına kadar çıkar. İnsuyu Mağarası merkeze yakın bir duraktır.
